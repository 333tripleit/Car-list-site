# Car list site

Минималистичный сайт-каталог автомобилей на границе Литва—Беларусь.

## Главное изменение
- Убрана локальная база автомобилей (`cars.json`) как источник карточек.
- Каталог формируется из **ссылок на посты Telegram**.
- Данные (включая фото URL) извлекаются из текста постов формата:
  - `🔥Audi Q3 / S-line🔥`
  - `🌟 Год 2019`
  - `🚗 Пробег: 76 300 км`
  - `⛽️ Двигатель: 1.5 бензин (150 л. с)`
  - `⚙️ Привод: полный`
  - `🔧 Коробка: автомат`

## Stack
- HTML5 + CSS3 + Vanilla JS (ES modules)
- Node.js built-in `http` server
- Источник ссылок: `data/telegram-links.json`

## Run
```bash
npm start
```
Открыть: `http://localhost:3000`

## Pages
- `/` — каталог авто с фильтрами
- `/admin` — импорт ссылок Telegram, предпросмотр, экспорт в JSON (включая фото URL)
