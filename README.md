# Car list site

Минималистичный сайт-каталог автомобилей на границе Литва—Беларусь.

## Главное изменение
- Убрана локальная база автомобилей (`cars.json`) как источник карточек.
- Каталог формируется из **ссылок на посты Telegram**.
- Данные (включая фото URL) извлекаются из текста постов формата:
  - `🔥Audi Q3 / S-line🔥`
  - `🌟 Год 2019`
  - `🚗 Пробег: 76 300 км`
  - `⛽️ Двигатель: 1.5 бензин (150 л. с)`
  - `⚙️ Привод: полный`
  - `🔧 Коробка: автомат`

## Stack
- HTML5 + CSS3 + Vanilla JS (ES modules)
- Node.js built-in `http` server
- Источник ссылок: `data/telegram-links.json`

## Run
```bash
npm start
```
Открыть: `http://localhost:3000`

## Pages
- `/` — каталог авто с фильтрами
- `/admin` — импорт ссылок Telegram, предпросмотр, экспорт в JSON (включая фото URL)

## Импорт одной ссылкой
Да, можно использовать **одну ссылку**:
1. Ссылка на конкретный пост (`https://t.me/<channel>/<id>` или `https://t.me/s/<channel>/<id>`) — загрузятся фото и описание именно этого поста.
2. Ссылка на канал (`https://t.me/<channel>`) — автоматически нормализуется в `https://t.me/s/<channel>` и берется актуальный пост.

## Игнорирование лишнего текста
- Парсер учитывает только блок с характеристиками (название, год, пробег, двигатель, л.с., привод, коробка).
- Маркетинговый хвост после блока (например, "Доставка", "любой регион", "Telegram: ...", "Цена ...") автоматически игнорируется в поле описания и разборе характеристик.

## Что нужно для корректного импорта данных + фото
1. Нужны **публичные** ссылки на посты Telegram (`https://t.me/...`), доступные без логина.
2. В посте должен быть текст со структурой полей (Год, Пробег, Двигатель, Привод, Коробка).
3. Фото должны быть прикреплены к посту (в экспорт попадут до 10 URL).
4. Если Telegram временно недоступен или пост закрыт, в результате вернется карточка с `Ошибка загрузки`.
